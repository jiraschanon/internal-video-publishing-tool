Internal Video Publishing Tool

This is an internal tool designed to automate video uploads to a user's own TikTok account using TikTok’s official APIs.

The application is intended for internal use only. It does not provide public-facing services, social features, or content discovery.

How it works

  • Users authenticate via TikTok OAuth
  • The app uploads videos on behalf of the authenticated user
  • All content is published only to the user’s own TikTok account
