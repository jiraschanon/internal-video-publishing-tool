Internal Video Publishing Tool

This internal web tool allows a user to authenticate with their own TikTok account and upload videos using TikTok’s official APIs.

1. TikTok Login

Users authenticate via TikTok Login Kit to grant permission to upload content.

Uses: Login Kit + scope user.info.basic

2. User Information

After login, basic profile information is retrieved from TikTok.

  • Username: sandbox_user
  • User ID: 123456789

Uses: user.info.basic

3. Upload Video to TikTok

The user selects a video file and publishes it to their own TikTok account.



Uses: Content Posting API + scope video.upload

4. Share & Data Access

The tool may optionally allow users to share published videos or export their data.

Uses: Share Kit, Data Portability API
